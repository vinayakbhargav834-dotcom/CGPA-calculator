# CGPA Calculator

A simple and easy-to-use **CGPA Calculator** made for students to calculate their CGPA using subject credits, grade points, and marks.

## About the Project

This project helps students calculate their CGPA without doing the calculations manually.

The calculator takes the required details for each subject and calculates the final CGPA based on the entered values.

## Features

* Enter subject credits
* Enter grade points
* Enter marks
* Convert marks into grade points
* Calculate CGPA
* Simple and clean interface
* Easy to use for students
* Works directly in the browser

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Open the CGPA Calculator.
2. Enter the credit for each subject.
3. Enter the marks or grade point.
4. Click the **Calculate** button.
5. The calculator will show the calculated CGPA.

## Grade Point System

The calculator uses the following marks-to-grade-point system:

|    Marks | Grade Point |
| -------: | ----------: |
|      90+ |          10 |
|    80–89 |           9 |
|    75–79 |           8 |
|    70–74 |           7 |
|    60–69 |           6 |
|    50–59 |           5 |
|    40–49 |           4 |
| Below 40 |           0 |

## Purpose

The main purpose of this project is to make CGPA calculation quicker and easier for students while also providing a practical project for learning HTML, CSS, and JavaScript.
